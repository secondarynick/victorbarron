# Victor Barron

Upgraded website for [victorbarron.com](https://www.victorbarron.com).

The full Next.js source lives on the Cursor branch `cursor/website-upgrade-6a67` and in [this pull request](https://cursor.com/codebase/nick-tiedemann/VictorBarron/pull/1).

## Deploy on Vercel

1. Import this GitHub repo in the [Vercel dashboard](https://vercel.com/new) once the app source is on `main`.
2. Framework: Next.js. Build command: `npm run build`.
3. After the first `*.vercel.app` URL is live, add `victorbarron.com` and `www.victorbarron.com` in Project → Settings → Domains.

No environment variables are required for the first deploy.
